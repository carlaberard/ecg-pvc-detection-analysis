# ECG PVC Detection and Analysis

MATLAB biomedical-signal-processing coursework on detecting and analyzing premature ventricular contractions (PVCs) in ECG recordings. Includes MATLAB scripts, a Live Script and the associated academic report.

## Contents
- `analysis/`: MATLAB Live Script and supporting functions.
- `report/`: Academic report.
- `images/`: Original representative PVC beat plot.

## Data availability
The original ECG `.mat` recordings are **not included**, because their public redistribution permission has not been checked. Reproducing the analysis requires suitable authorized ECG recordings in the expected format.

## Tools
MATLAB.

## Notes
The project is an educational analysis, not a validated arrhythmia detector for clinical use.
